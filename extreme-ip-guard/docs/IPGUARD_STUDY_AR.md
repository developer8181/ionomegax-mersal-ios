# دراسة IP-guard وموقع Extreme IP Guard

## ما هو IP-guard؟

**IP-guard** (Teclink Development) منصة أمن وإدارة داخلية للمؤسسات تركز على:

1. **منع تسريب البيانات (DLP)** — البريد، الطباعة، USB، المراسلة، المشاركة.
2. **مراقبة الحاسوب والإنترنت** — المواقع، التطبيقات، النطاق الترددي، الامتثال.
3. **إدارة الأنظمة** — الأصول، التصحيحات، النشر عن بُعد، اكتشاف الأجهزة غير المصرح بها.
4. **أمان نقاط النهاية** — تشفير الوسائط، حظر Bluetooth/Wi‑Fi/USB، التحكم بالشبكة.

المنتج يُباع كنظام **وحدات متعددة** (حوالي 14 وحدة) يُدار من **وحدة تحكم مركزية** ووكلاء على Windows غالبًا.

## نقاط القوة التقليدية

- تغطية واسعة لسيناريوهات المكتب الداخلي.
- سياسات مركزية وتقارير للامتثال.
- تنبيهات فورية عند محاولات اتصال غير مصرح بها.
- نضج السوق في قطاعات الحكومة والمالية.

## قيود الجيل القديم (فرصة Extreme IP Guard)

| المجال | IP-guard التقليدي | Extreme IP Guard المستهدف |
| --- | --- | --- |
| نموذج الثقة | شبكة داخلية «موثوقة» جزئيًا | **Zero Trust** — تحقق مستمر |
| التحليل | قواعد ثابتة + تقارير | **UEBA** + درجة مخاطر ديناميكية |
| التدقيق | سجلات قابلة للتعديل من المسؤول | **سلسلة تجزئة** (immutable audit chain) |
| التكامل | واجهات مغلقة | **MITRE ATT&CK**، SOAR، SIEM، webhooks |
| الشبكة | حظر منافذ/اتجاهات | **مستشعر حافة** + تصنيف شرائح (segments) |
| التشفير | TLS تقليدي | جاهزية **Post-Quantum hybrid** (خطافات) |
| الرؤية | عميل سطح مكتب | عميل + **eBPF taxonomy** للأحداث على Linux |

## خريطة الوحدات → مكونات Extreme

| وحدة IP-guard | مكون Extreme | الحالة في النموذج |
| --- | --- | --- |
| DLP | محرك سياسات + `dlp_probe` (مخطط) | قواعد regex + أحداث |
| Network Management | `network_sensor.py` | محاكاة lateral/port scan |
| Endpoint Security | `client_agent.py` | posture + USB |
| PC/Internet Monitoring | فئات `web` / `application` | قواعد سياسة |
| Systems Management | تكامل ITSM (مخطط) | — |
| Document Security | DLP + طباعة | فئة `print` |

## الهدف الاستراتيجي

**Extreme IP Guard** ليس نسخًا من IP-guard، بل **منصة الجيل التالي**:

- حماية **البيانات والسلوك والهوية** معًا.
- قرار أمني واحد: `allow | warn | block | quarantine | isolate`.
- لوحة SOC موحدة بالعربية والإنجليزية.
- قابل للاستضافة الذاتية بدون تبعيات خارجية (Python stdlib).
