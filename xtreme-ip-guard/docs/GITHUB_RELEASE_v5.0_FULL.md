## العربية

### عن النظام والمؤسسة

**Mersal XDR Enterprise Platform** من **Ionomegax** — منصة أمن سيبراني موحّدة بديلة لأنظمة EDR و SIEM و SOAR وإدارة الثغرات و GRC المنفصلة.

- **المهندس:** محمود راسم بياري — مهندس أنظمة الحماية، رام الله، فلسطين  
- **الشركة:** Extreme Technology (إكستريم تكنولوجي)  
- **الحقوق:** © 2009–2026 — جميع الحقوق محفوظة  

### المزايا الرئيسية

1. **Mersal XDR** — ارتباط عبر الطبقات (SIEM + EDR + ثغرات + Suricata) مع عزل تلقائي  
2. **Mersal SIEM** — تنبيهات SOC وقواعد ارتباط وربط MITRE ATT&CK  
3. **Mersal EDR** — مراقبة عمليات وشبكة وقواعد YARA  
4. **Mersal Log Vault** — تجميع وبحث السجلات المركزي  
5. **Mersal Neural Cortex** — ذكاء اصطناعي دفاعي محلي  
6. **Mersal SOAR** — استجابة آلية و Playbooks  
7. **CISA KEV** — تغذية ثغرات مستغَلَة معروفة  
8. **Command Center** — واجهة عربية/إنجليزية حية
