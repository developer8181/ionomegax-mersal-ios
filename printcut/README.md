# PrintCut Pro — نظام إدارة الطباعة والقص

نظام متكامل لإدارة أعمال الطباعة والقص (Print & Cut) مشابه لبرنامج PrintCut، مبني بتقنيات حديثة.

## الميزات الرئيسية

### 🖨 إدارة الطلبات
- إنشاء وتتبع طلبات الطباعة والقص
- تحديث حالة الطلبات (انتظار → تصميم → طباعة → قص → مكتمل)
- تعيين الأولويات (عادي / عالي / عاجل)
- تتبع المبالغ والدفعات
- فلترة وبحث متقدم

### ✂ بيئة التصميم
- لوحة تصميم تفاعلية مع أدوات:
  - أشكال: مستطيل، دائرة، مثلث، خط
  - نصوص بأحجام مخصصة
  - تحريك ونسخ وحذف العناصر
- **طبقات مستقلة**: طباعة فقط / قص فقط / طباعة وقص
- **خط القص (Cut Contour)**: يظهر بالخط المتقطع الأحمر
- **علامات التسجيل (Registration Marks)** التلقائية في الزوايا
- تصدير التصميم كـ PNG

### 🖨 طابور الطباعة
- إدارة مهام الطباعة بالطابور
- تتبع التقدم في الوقت الفعلي
- إعدادات الطابعة

### ✂ طابور القص
- إدارة مهام القص
- إعدادات النصل: السرعة والضغط
- دعم أجهزة Graphtec, Roland, Mimaki, Silhouette
- قوالب إعدادات جاهزة (فينيل رقيق/عادي/سميك)

### 👥 إدارة العملاء
- قاعدة بيانات العملاء
- عرض سجل الطلبات والإيرادات لكل عميل

### 📦 إدارة المواد والخامات
- تسجيل أنواع الفينيل، الورق، الكانفاس، PVC
- تتبع المخزون مع تنبيهات المخزون المنخفض

### 📊 التقارير والإحصائيات
- الإيرادات الشهرية
- معدل إنجاز الطلبات
- توزيع حالات الطلبات
- أفضل العملاء
- استهلاك المواد

## التقنيات المستخدمة

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand
- **Charts**: Recharts
- **Icons**: Lucide React
- **Routing**: React Router DOM

## تشغيل المشروع

```bash
# تثبيت الاعتمادات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء للإنتاج
npm run build
```
