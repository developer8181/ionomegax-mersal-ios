# Print Cut Studio

نظام ويب مفتوح المصدر للتصميم والطباعة والقص (Print & Cut) — مشابه لسير عمل برامج مثل EasyCut و VinylMaster و Creation PCut.

## المميزات

- لوحة تصميم بالمليمتر مع أشكال ونصوص واستيراد SVG
- أوضاع الطبقة: طباعة فقط · قص فقط · طباعة + قص
- إنشاء خط قص (Contour) حول العنصر المحدد
- علامات تسجيل (Registration Marks) في الزوايا للمحاذاة بين الطابعة والقاطعة
- تصدير SVG للطباعة و SVG للقص
- تصدير HPGL للقاطعات (معكوس محور Y حسب ارتفاع اللوحة)

## التشغيل

```bash
cd print-cut-studio
npm install
npm run dev
```

ثم افتح العنوان الذي يعرضه Vite (عادة `http://localhost:5173`).

## سير العمل الموصى به

1. صمّم التصميم أو استورد ملف SVG.
2. أنشئ خط القص وأضف علامات التسجيل.
3. صدّر `print.svg` واطبعه من برنامج الطباعة مع ترك الهوامش.
4. ضع الورقة على القاطعة وحمّل `cut.hpgl` (أو `cut.svg` حسب دعم الجهاز).
5. اضبط نقطة الأصل والمحاذاة باستخدام علامات التسجيل على الجهاز.

## ملاحظات تقنية

- وحدات HPGL: 40 وحدة = 1 مم (شائع في كثير من القاطعات).
- قد تحتاج لتعديل إعدادات السرعة والضغط من لوحة القاطعة نفسها.
- للإنتاج المتقدم: ربط USB/Serial/TCP يتطلب جسراً محلياً (غير مضمن في هذا الإصدار).

## الترخيص

مضاف كمشروع مستقل داخل مستودع Monal؛ يمكن نقله لمستودع منفصل لاحقاً.
