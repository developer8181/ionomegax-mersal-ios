# PrintCut - نظام التصميم والقص

نظام تصميم وقص متكامل يعمل على المتصفح، مشابه لبرنامج PrintCut. يتيح لك تصميم الملصقات والعلامات والرسومات مع إمكانية إنشاء خطوط القص وتصديرها.

## المميزات

### أدوات التصميم
- **أداة التحديد** - تحديد ونقل وتغيير حجم العناصر
- **أداة التحريك** - تحريك مساحة العمل
- **القلم والرسم الحر** - رسم مسارات حرة
- **الأشكال** - مستطيل، دائرة، مضلع، نجمة
- **خط مستقيم** - رسم خطوط مستقيمة
- **النص** - إضافة نصوص بخطوط مختلفة
- **الصور** - استيراد وتعديل الصور

### نظام القص
- إنشاء خطوط قص تلقائية حول التصاميم (كنتور)
- تحكم في إزاحة خط القص عن حافة التصميم
- أنواع زوايا مختلفة (مستديرة، حادة، مشطوفة)
- علامات تسجيل للمحاذاة
- معاينة القص قبل الإرسال

### التصدير والحفظ
- تصدير PNG بجودة عالية
- تصدير SVG (مع خطوط القص)
- طباعة مباشرة
- حفظ وفتح المشاريع بصيغة `.printcut`

### إدارة الطبقات
- إضافة وحذف طبقات
- إخفاء/إظهار الطبقات
- قفل الطبقات
- ترتيب الطبقات

### واجهة احترافية
- واجهة عربية بالكامل (RTL)
- وضع داكن مريح للعين
- شبكة ومساطر قابلة للتخصيص
- اختصارات لوحة المفاتيح
- تراجع/إعادة (Undo/Redo)

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح أو استخدم أي خادم محلي:

```bash
# باستخدام Python
python3 -m http.server 8080

# أو باستخدام Node.js
npx serve .
```

ثم افتح المتصفح على `http://localhost:8080`

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|----------|---------|
| V | أداة التحديد |
| H | أداة التحريك |
| R | مستطيل |
| C | دائرة |
| L | خط |
| T | نص |
| B | رسم حر |
| P | قلم |
| Ctrl+Z | تراجع |
| Ctrl+Y | إعادة |
| Ctrl+C | نسخ |
| Ctrl+V | لصق |
| Ctrl+A | تحديد الكل |
| Ctrl+S | حفظ المشروع |
| Ctrl+D | تكرار |
| Delete | حذف المحدد |
| Escape | إلغاء التحديد |

- Font Awesome Icons
